# Standalone Third-Party Components

The standalone archive includes files from [RE-UE4SS](https://github.com/UE4SS-RE/RE-UE4SS), distributed under the MIT License included as `UE4SS-LICENSE` in the archive.

The pinned binaries and base Lua mods are sourced from `Thunderstore-unreal_shimloader` 1.1.7. The standalone archive does not include the shimloader binary itself; it includes only the packaged UE4SS overlay needed for direct installation.

- Source package: <https://thunderstore.io/package/Thunderstore/unreal_shimloader/1.1.7/>
- Package SHA-256: `8deaf2a7246370f4e30f65af37645cdef481a28cb353d7285c3a62576bcba853`
- UE4SS build: `v3.0.1-932-ge31aaaa6`
